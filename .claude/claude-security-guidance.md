# Security guidance: metavert-io/metarush

Generated by the Security Steward from `security/threat-model.yaml` (model v1, reviewed at 4dc6854cb97d). Edit the model, not this file.

A video-production harness that runs on its owner's Mac, published to the owner's tailnet: a web dashboard and API, a dashboard assistant (Claude Code in a read-only workspace), link import, media processing and rendering, and the cloud accounts those use.

## What this system protects

- C1 Web dashboard and API (tailnet)
- C2 Dashboard assistant (Claude Code) (local)
- C3 Link import
- C4 Media parsers and transcription (local)
- C5 Render sandbox (local)
- C6 Cloud credentials (storage, database, voice, video and model APIs, YouTube)
- C7 CI and release builds

## Assumptions

- A1: The dashboard is reachable only on the owner's tailnet, never through Funnel.

## Keep in mind when changing code

- T-MR-0001 (mitigated, STRIDE:S CWE-307 CWE-916 ASVS:5.0.0:V6): Accounts are taken over by guessing or cracking passwords. Relies on M-MR-0001
- T-MR-0002 (mitigated, STRIDE:T CWE-352 ASVS:5.0.0:V3): Another site makes the signed-in browser act on the dashboard. Relies on M-MR-0002
- T-MR-0003 (mitigated, STRIDE:S CWE-290): Forged Tailscale identity headers, or exposure through Funnel. Relies on M-MR-0003
- T-MR-0004 (mitigated, STRIDE:E ASI02 ASI03 LLM06): The assistant is steered into changing things instead of reading them. Relies on M-MR-0004
- T-MR-0005 (mitigated, STRIDE:I CWE-798): A secret is committed to the repository. Relies on M-MR-0005
- T-MR-0006 (mitigated, STRIDE:T CWE-1357): A compromised third-party GitHub Action runs in CI. Relies on M-MR-0006

## Controls that must stay in place

- M-MR-0001: argon2id passwords, sessions stored only as hashes, lockout and per-address limits (`internal/api/access.go`)
- M-MR-0002: SameSite=Strict __Host- cookies and a required CSRF header (`internal/api/access.go`)
- M-MR-0003: Host guard: Tailscale headers accepted only from loopback; Funnel refused (`internal/api/access.go`)
- M-MR-0004: Assistant tool allowlist, read-only command shim, CLI guard and ops dispatcher (`internal/assistant/workspace.go`)
- M-MR-0005: gitleaks, pinned by checksum, over the full history in CI (`.github/workflows/secret-scan.yml`)
- M-MR-0006: Actions pinned by commit SHA (`.github/workflows/ci.yml`)
