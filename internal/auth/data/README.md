# common-passwords.txt.gz

Every password of 12 to 128 characters in SecLists' `Passwords/Common-Credentials/Pwdb_top-1000000.txt`
(https://github.com/danielmiessler/SecLists, MIT licence, Copyright (c) 2018 Daniel Miessler), NFKC-normalized,
lower-cased and de-duplicated (29,954 lines). MetaRush refuses these as passwords; shorter ones are refused by
the length rule. Regenerate with the same filter when updating.
